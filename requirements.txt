# (https://github.com/epics-containers/pvi/pull/203). 0.14.5 connects write buttons
# to their PV (https://github.com/epics-containers/pvi/pull/210), and is the current
# release.

# and 'ibek dev sync'. This must become a release pin (ibek>=X.Y.Z,<N) before
# this is merged.
git+https://github.com/epics-containers/ibek.git@dev-sync-prebuilt
